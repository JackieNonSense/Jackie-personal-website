## 1. 不变量与层级

相机固定正面；静态机壳和顶部导轨不旋转、不呼吸、不随鼠标倾斜。
整块可动前面板包含黑玻璃、V 型银色折面、中央旋钮、四枚冰蓝键。绕底部横向真实铰链转动；不是上屏和下旋钮分成两个自由漂浮面。
显示内容处于玻璃后；反射随几何角度变化，不用另一个任意扫光动画代替。
机身不新增 JACKIE，不用随机设备编号或虚构功能填空。保留网页署名。
概念板为阅读而压缩了部分机身比例；建模仍以用户批准 A 原图的宽高比为准。分镜不作为精密工程图。

## 2. 控件映射（建议，待实现）

- 左上 PLAY/PAUSE：播放、暂停、失败时重试。
- 左下 NEXT：按既定曲序循环换碟。
- 右上 DISPLAY：建议在同一个 A 显示窗内切换实时频谱/时域示波，不改变 EQ 或音色；不更改 A 硬件造型。
- 右下 MUTE：只静音输出，保持播放位置继续推进和原音量。
- 中央旋钮：上下拖动调音量，短按也可静音；保留独立可访问音量输入。
所有动作必须有等价 HTML 控件和清晰名称。可见按键虽小，命中区应至少 44 CSS px 且互不覆盖；不足时移动端在设备下方布局真实控件。

## 3. 微交互

Hover/focus 约 80ms：仅命中键帽的冰蓝边缘增加约 15–20% 亮度，离开约 120ms 恢复；不点亮全屏、不出声。键盘 focus 另有可辨边界。
按压约 100ms：键帽沿自身局部法线压入约 1mm（最终以模型尺寸校准），释放约 120ms 过阻尼回位，无反复弹跳。
pointerdown 只表现按压，click 才执行；拖出取消/pointercancel 复位，不误触。
旋钮映射：0–100% 对应约 240°，25→55 对应 72°。从初始指针位置计算 deltaY，不在抓取时跳变。建议 150 CSS px 竖向行程覆盖全部音量；桌面 Shift 拖动可选细调，非首版必要。
超过 5 CSS px 视为拖动，禁止释放时再触发 mute。pointer capture 保持连续操作；丢失捕获清理状态。
拖动无弹簧滞后，控制值即时更新，显示数值与指针同源；音量增益约 20–30ms 短平滑。松手无惯性继续变大声。
短按静音与拖动互斥；静音下旋钮可调整保存音量但不解除静音，避免突然出声。
旋钮 tick/刻纹/材质随网格真实旋转。环境反射依表面法线变化，不把全部高光固定烘焙后旋转贴纸。
不启用旋钮 hover 滚轮调音量，避免截走页面自然滚动。

## 4. 首次播放

初始 READY，默认音量25%，无声，不下载整首音乐；弱按键背光保留可操作性。
点击立即按键反馈，并在同一次用户手势调用真实播放/解锁声音；不能先等视觉序列结束再请求。
加载时显示 LOAD/LOADING，无虚构百分比；真实 playing 确认前时间与频谱不运行。
确认后显示区域可按约 50ms 间隔依次显现：音量刻度、曲名、时间/状态；这是可见层级，不是阻塞声音的启动关卡。首次总视觉过渡约 200–300ms。恢复暂停不重播开机序列。
真实频谱建议约 50ms attack / 180ms release，峰值停留约 100ms 再下落；实际响应需在浏览器依试听曲调试，不是随机动画。
暂停约 200ms 声音淡出后保留位置，谱柱约 180ms 回基线，PAUSE 持续可读。静音同样可短淡出，但时间继续，MUTE 可读；源信号频谱可继续低亮运行，需取样于输出静音增益之前，不能凭空编造静音频谱。

## 5. NEXT 时间轴（样机目标，不是已测时长）

从 NEXT 点击起约1200ms：
- 0–180ms：确认输入，NEXT 键回位，旧曲淡出；频谱回落，曲名变 CHANGE，面板仍闭合。
- 180–450ms：同一前面板绕底轴前翻，目标约28°（几何校准后允许小调整）；ease-in-out，起步/结束柔和但无弹跳；内仓持续存在。
- 450–630ms：碟片沿内部导轨短暂退出，露出窄银弧，保持水平而非朝观众竖直全圆。
- 630–850ms：碟片回入；完全遮挡时替换虚拟盘面/曲目信息。表现自动换片隐喻，不声称是一台物理单碟机真的能够凭空交换两张 CD。正常 CD 换曲不退碟，此处保留用户要求的每首一张虚拟唱片的创作前提。
- 850–1050ms：面板回收，大部分行程完成；最后几度慢下来，黑色接缝变细，高光随折面自然收束，不添加人为撞击闪白。
- 1050–1200ms：已落位且音频就绪且用户仍想播放，才新曲淡入，时间/真实频谱启用；否则显示等待或暂停，不假装出声。
图中 06 SEATED 是声音已经开始后的示例，不代表所有网络条件都能1200ms完成。
若面板遮挡过大，优先修铰链/间隙而不是改摄像机；保留正面观看。

## 6. 取消与异常

- 切换中暂停立即改变播放意图；机械完成安全落位，但新曲不可自动开声。
- 暂停时 NEXT 执行静音换片，落位仍 PAUSE。
- 下一首执行期间禁用重复切换，不堆队列；播放/暂停始终有可用控件，面板运动期间可由固定 HTML 小控制承接。
- 失败收敛到闭合安全状态，显示 LOAD FAILED，提供 Retry/Next，不无限循环开关或频谱。
- 快速播放/暂停使用最新意图与请求版本校验，过时 Promise 不得重启音频。
- 切后台/离视口停绘制但音乐继续；机械计时需能安全完成，不以 RAF 驱动音频状态。恢复时呈现当前稳定状态，不快放错过动画。
- 离开首页进入 terminal 停止并释放音频，返回不自动播放。
- 减少动态效果/暂停视觉：不翻面、不转旋钮网格、不跳频谱，直接更新文字、刻度静态值和控件状态；声音独立可用且保留淡变。
- 静态 poster 和真实模型用同一模型/灯光输出；冷加载切换不改变机身颜色和形体。WebGL 失败真实 HTML 控制仍可用。

## 7. 实施边界与验收

沿用现有首页播放器；扩展阶段而非另建第二套音乐状态源。
Motion 用于外层状态/键盘反馈，Three.js 用于铰链、旋钮、键帽和玻璃；不让两者竞争同一 mesh 属性。不照搬 skill 中整组件浮动/缩放示例，因为与用户物件稳定要求冲突。
先用确定性时间测试验证音频意图、取消、阶段；再做静态模型与单控件；最后接换碟。
保存实际浏览器录像，检查标准视口390×844/1440×900/1920×1080、拖出/触控取消、加载失败/权限拒绝、快速操作、后台与减少动态效果。不能把本轮分镜称作已经实现的动画或性能证据。
最终触控图的白箭头属于分镜标注，不出现在网页。第一稿暂停频谱未收束、转角不足，已生成修正版；微观划痕/字形仍可变，不覆盖原始造型约束。
