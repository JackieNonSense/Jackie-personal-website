## Shared decisions from the user

- The aperture is an atmospheric website interaction, not an independent portfolio work.
- Remove the INKTRACE word-coalescing and click-to-lock mechanism from the proposed next version. Symbols should form vertically moving columns, with subtle rising/falling drift, not a horizontal ticker or waveform.
- Hover gently separates the upper and lower paper lips, suggesting a space behind the surface. Concept illustrations exaggerate the opening for readability. Proposed implementation starting point: 12–18 CSS px per lip, to be calibrated in the browser, not applied as a measured final value.
- A future implementation needs separate upper/lower paper layers, a persistent recessed backing and a matching character clip; translating an opaque whole material plate would expose the wrong background. Name, navigation and reading position should remain stable.
- Keyboard focus and touch need an equivalent discoverable preview. No fast flashing, forced entry, autoplay audio or loss of ordinary work navigation. Reduced-motion mode should keep the scene readable and minimize movement.
- Remove Signal Study. The existing monitor becomes the sole object in Experiments, with a real compact 3D CRT preview plus an ordinary terminal link.

## A — network city fragment

A compact metropolitan slice in the right side of About, mixing graphite architecture, cobalt edges and a sparse dissolving point cloud. Intended interaction: restrained pointer parallax and bounded drag rotation, not automatic continuous spinning or a playable city. The name and bio remain primary.

Monitor direction: warm grey ABS, curved dark glass, subtle seams, vents, a small stand and a dim green phosphor screen. No extra desktop props.

## B — dimensional internet window

A shallow old software-window frame reveals a disproportionately deep wireframe corridor. Intended interaction: pointer position changes the view into the corridor; near and far layers respond differently. It should feel like a small opening into an unknown internet, not a dashboard.

Monitor direction: graphite shell, warm-grey bezel, faint cobalt rim and a compact green terminal display. Generated incidental markings or text are not final branding/copy.

## Existing implementation inspected

`components/terminal/RetroComputer.tsx` already contains a geometric monitor shell, bezel, screen, vents, buttons and a base unit. It is a reusable starting point, not a guarantee of concept-image visual quality. `TerminalScene.tsx` is the existing full scene; the proposed homepage preview should stay independent from the terminal's internal flow.
