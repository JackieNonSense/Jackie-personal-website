# SEED：Jackie Random 的个人终端

设计文档 v0.1，2026-09-24。标 **【待定】** 的地方需要你来决定或补充。

人物、时间线、线索、照片和内容文件的对照在 [story.md](story.md)。

---

## 0. 核心

- **类型**：科幻悬疑，探索游戏。
- **玩完的感觉**：虚无。没有拯救，也没有答案。
- **气质参考**：攻壳机动队、银翼杀手 2049、黑客帝国。
- **入口**：不需要密码，谁都能开机。通关后会得到一串密码，用来解锁主页上的东西（见第 7 节）。
- **一句话**：你打开了 Jackie Random 的个人终端，想弄清他去了哪里；最后你发现，这台机器上的一切，可能包括你自己，都是从他这颗"种子"生成出来的。

## 1. 世界观

### 溺水

不久的将来，网络上几乎所有内容都由机器生成。模型开始用自己的产出训练自己，一代比一代更平、更像、更灰（现实中这叫"模型崩溃"）。网络在自己的回声里淹死了，所有东西都变得死气沉沉。

### 种子

机器发现，只有真正的人类原创才能阻止生成世界继续退化。这些原创被称为"种子"。

人被安置在房间里，接入系统，不停地创作。他们瘫坐在地上，眼神空洞，产出被收走、筛选，再喂给机器。这些人被称为"供体"。

### Random

在程序里，一切"生成"都从一个随机种子（random seed）开始：同一个种子，永远生成同一个世界。

**Jackie Random 的名字就是这个故事的钥匙。** 不做解释，留给玩家自己反应过来。

## 2. 角色

| 角色 | 是谁 |
|---|---|
| **Jackie Random** | 少数还在真正创作的人。他拔掉网线，把自己的东西存在 N.O. 送的老机器上；这台机器只剩一根电话线通向外面。 |
| **你（玩家）** | 一个开机的人，不知道自己为什么坐在这台机器前。 |
| **系统** | 看不见，但无处不在。终端开机时说 `Welcome back, Jackie.`，因为它分不清坐在前面的是谁。 |

---

## 3. 结局：Y，再叠一层 X

**Y：他从来就是种子。** 这台机器上的东西，包括他的日记和作品，有一部分，甚至可能全部，是系统从他这颗种子生成出来的变体，已经分不清哪个是原件。

**叠上 X：** 你坐在这里一个字一个字地打，本身也成了他的又一个变体。状态栏角落有一个从开机就在跳的计数器，你输入的每个字都被记录着。

最后，系统要求你"提交一颗种子"。你输入什么都行，它回你一串编号：`SEED ACCEPTED`。这串编号就是通关密码。

## 4. 机器里有什么

### 4.1 开机

1. **台标**：一块 J&R 铭牌像老电视台的台标一样出场、再像关电视一样收成一个亮点。
2. **BIOS 自检、系统配置、DOS 启动**：N.O. Electronics 的 BIOS，配合硬盘声。
3. **加载 JR-DESK**：真实的预读进度。
4. **登录**：密码自己打出来。
5. **问候**：`Welcome back, Jackie.`（第一条线索，一开始只像一句亲切的招呼）
6. **跳过**：每一段都可以按任意键快进，ESC 直接到登录；回访的玩家启动更短。

详细见 [story.md](story.md) 第 6 节。

开机和菜单都没有背景音乐。声音只来自机器本身：电源开关、CRT 消磁、硬盘和风扇、键盘、电视旋钮，放在一个安静小房间的空间感里。只有自检蜂鸣、游戏和电视走喇叭。音乐只在特定场景出现。

### 4.2 BBS：他的小站（A）

他给自己开的站，只让几个老朋友拨进来。这是整个故事里最有生气的一层，也是第一次来的人会逛的地方。现在做成了像素图形桌面，点图标、拖窗口就能逛，读起来就像一个很酷的作品集（操作见 [story.md](story.md) 第 6 节）。

- **留言板**：来客越来越少，后来留言的全是机器人：礼貌、流畅、空洞。
- **作品**：他的小游戏、画、图文小说（见 4.5 到 4.7）。
- **关于**：他写的自我介绍。

### 4.3 Shell：他的私人文件（B）

给好奇的人的深层，用真实的命令行操作：`dir`、`cd`、`type`……

- **日记**（见 4.4）。
- **系统日志**：种子收集量在变化，他的"产出"被记录着。
- **被删除的文件**：可以恢复一部分，是关键线索。

### 4.4 日记：三段起伏

你来写。讲一个逐渐崩溃、中途好转、又遭遇某件事而彻底崩溃的人。

| 阶段 | 内容 | 对应剧情 |
|---|---|---|
| 一、下沉 | 世界越来越灰，他越来越难做出东西。 | 第一幕，表面。 |
| 二、好转 | 他重新开始创作：写东西、做小游戏、BBS 又热闹起来。 | 第二幕，BBS 上最有生气的内容大多出自这个时期。 |
| 三、彻底崩溃 | 某件事发生。 | 第三幕，真相。 |

**提议（你可以换掉）**：让他彻底崩溃的那件事，是他发现好转时期的作品不是他做的，而是系统从他生成的变体。连"好起来"都不是他自己的。

- 日记越往后越短，越来越像系统日志，最后只剩 `output nominal`。
- 日记里的日期、断档和前后矛盾，本身就是线索。

【待定】日记的原稿。先写成什么样都行，之后一起改。

### 4.5 他做的小游戏（带背景音乐）

在终端里直接运行，鼠标或手指控制，键盘也能玩。

- 在故事里，它们是他"好转时期"的作品，因此也可能是变体。
- 可以埋细节：比如最高分记录的时间是他在日记里说自己睡着的时候，或者同一个游戏存在几个几乎一样的版本。

【待定】游戏的点子，先列几个。

### 4.6 图文小说 / 二次元

用 PC-98 风格：插画转成绿色单色抖动像素图，配文字一页页读。

- 在故事里，这是他在写的东西，所以也是一颗种子。
- 插画最好是亲手画的，或者请人画（见第 5 节的规则）。

【待定】故事内容，以及插画从哪来。

### 4.7 电视频道（C）

他每晚都看的生成频道：←→ 换台，频道之间是雪花。

- 每个频道都是上一个频道的"复制品的复制品"，一台比一台更糊、更平，最后只剩雪花。这等于把模型崩溃演给玩家看。
- 内容可以是 ASCII 动画艺术、生成的二次元图、新闻片段、广告……
- 他在某个频道旁边写过一行注释，是一条线索。

## 5. 一条贯穿的规则：手工的归种子，生成的归频道

- **种子**（日记、小游戏、他的画、图文小说）：尽量真的是人亲手做的。
- **频道**（生成世界的产物）：可以放 AI 生成的内容，而且应该让它退化。

作品本身就是在践行故事的主题。

音乐也适用这条规则：他的游戏音乐是种子，频道里的音乐可以是生成的，也可以故意做得失真、循环、空洞。

## 6. 剧情节奏（15 到 25 分钟）

| 幕 | 玩家在做什么 | 发现了什么 |
|---|---|---|
| **一、表面** | 开机，逛 BBS，读作品，玩一个小游戏。 | 一个安静、很酷的个人终端。只有 `Welcome back, Jackie.` 有点怪。 |
| **二、裂缝** | 进 shell，翻日记，换台。 | 日记的起伏；留言全是机器人；频道在退化；日期对不上。 |
| **三、真相** | 恢复被删除的文件，读到日记的最后。 | 他就是种子；好转时期的作品是变体；状态栏的计数器一直在记录你。 |
| **结局** | 提交一颗种子。 | `SEED ACCEPTED` 和一串编号，也就是密码。 |

- 大多数人只会逛第一幕，也不会觉得少了什么。
- 三条路（BBS、shell、电视）都能通向真相，不设硬谜题，不需要攻略。

## 8. 技术上需要新增的

| 能力 | 说明 |
|---|---|
| **图形模式** | 在 640×400 的光栅上直接画像素图，用于插画、游戏画面和 ASCII 动画。现在的 CRT 渲染本来就是一张像素图，所以改动很小。 |
| **音频系统** | 游戏和特定剧情场景的音乐；机器本身的声音（开关、消磁、硬盘、风扇、键盘、电视旋钮）。 |
| **游戏运行时** | 小游戏在终端内运行，统一处理鼠标、手指、键盘、帧循环，以及程序崩溃的结尾。 |
| **桌面框架** | 像素图形桌面：窗口、菜单、列表、对话框，鼠标和手指操作，键盘辅助。 |
| **文件系统和 shell** | 一个虚构的文件系统，加上 `dir`、`cd`、`type`、恢复删除文件等命令。 |
| **存档** | 在访客自己的设备上记住进度，比如读到了哪里、是否通关。 |
| **排版** | 所有文字要能同时适配 80 列（电脑）和 40 列（手机）；字符画需要宽、窄两个版本。 |

## 9. 建议的开发顺序

1. **框架**：BBS 导航、shell 与文件系统、图形模式、音频系统、开机。（已完成，见第 11 节）
2. **故事骨架**：先用占位文字把三幕和线索全部连通，确认能玩通。
3. **内容**：填入日记、第一个小游戏、频道。
4. **扩展**：图文小说、更多游戏。
5. **收尾**：结局，以及主页上的密码、three.js 物件和致谢动画（依赖主页重设计）。

## 11. 框架现状（2026-09-24）与内容填在哪里

框架已经搭好，所有内容目前都是占位的（标着 `[PLACEHOLDER]`）。要填内容，改 `components/terminal/content/` 下面这些文件就行，不需要动引擎代码。

| 要填的东西 | 文件 | 说明 |
|---|---|---|
| 开机画面的文字、拨号号码、logo | `content/bbs.ts` 里的 `BOOT` | logo 会自动用 VGA 字体生成大字；手机上显示 `logoNarrow` |
| 主菜单有哪些项 | `content/bbs.ts` 里的 `mainMenu()` | 每项一个字母热键 |
| 留言板、作品 | `content/board.ts` | 作品可以带链接，阅读时按 O 打开 |
| 日记、日志、隐藏文件 | `content/disk.ts` | `deleted: true` 的文件要用 UNDELETE 恢复，而且要补对被抹掉的首字母；`hidden: true` 的文件不会被列出 |
| 电视频道 | `content/channels.ts`、`content/tv/` | 频道 2 到 13，节目见 story.md 第 6.3 节；第 8 台先是雪花 |
| 图文小说 | `content/bbs.ts` 里的 `STORY` | 每页可以有图、说话人、文字 |
| 插画 | `scripts/build-terminal-picture.py` | 把任意图片转成 PC-98 风格的抖动图，放进 `public/terminal/pictures/` |
| 小游戏 | `content/games/` | 参考 `fall.ts`；在 `bbs.ts` 的 `PROGRAMS` 里登记，再在 `disk.ts` 里放一个 `.EXE` 文件，shell 里就能直接运行 |
| 音乐 | `audio/tracks.ts` | 默认没有背景音乐，只在特定场景播放（目前只有游戏）。`THEME` 留着，给需要音乐的剧情场景用 |

**两种屏幕宽度**：电脑上是 80×25，手机上是 40×12。文字会自动换行；字符画需要准备宽、窄两个版本。

**手机上怎么返回**：每个全屏程序右上角都有关闭按钮，列表的第二页左上角有"◄ 返回"。
