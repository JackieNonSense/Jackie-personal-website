## 已确认的设计判断

1. 巨大、极窄、局部出框的姓名是构图主体，不是普通标题。
2. 横向撕裂是唯一主要材料事件；它具有不规则轮廓，而不是周期性波浪。
3. 黑纸位于浅色纸上方：这是撕开黑纸后的开口，不是把白丝带贴到黑底上。
4. 绿色是局部发光信号；蓝色是少量印刷信息与墨迹。两者的物理观感不同。
5. 微型导航清晰且有真实用途。不能为了复古降低所有文字的可读性。
6. 惊喜来自后续可操作反馈，不通过继续增加装饰物实现。

## 图层合同

从底到顶组织。一个物理层不必对应一个文件，也不必对应一个 Canvas。

| 层 | 交付形态 | 职责 | 首轮是否运动 |
| --- | --- | --- | --- |
| 01 黑纸与撕裂底纸 | 无文字、无代码、无波形的高分辨率不透明材质图 | 保住纸边、纤维、接触阴影与黑场关系 | 否 |
| 02 姓名 | 独立排版；待确认字形来源及许可；配侵蚀遮罩 | 保证字形与裁切，不依赖用户系统 Impact | 否 |
| 03 蓝色印刷信息 | 独立文字/矢量与少量墨迹资产，限制在正确区域 | 印刷感，不发光，不用整齐蓝色竖条替代 | 否 |
| 04 信号暗部、亮芯和辉光 | 先验证静态波形，再决定 Canvas/SVG/WebGL 实现 | 保持细节密度、非周期轮廓与局部发光 | 否 |
| 05 导航与状态 | HTML 真实链接、按钮和状态文本 | 可读、可聚焦、可操作 | 仅后续必要反馈 |

### 为什么第一张是合并纸张材质板

真实撕纸的边缘、纤维与接触阴影相互依赖。第一轮将黑纸和露出的浅色底纸保存在同一张干净材质板里，降低重建接缝产生假描边的风险。姓名、信号、代码和导航均不包含在图内，因此它不是完整概念图充当网页的截图假实现。

这张板的限制也必须明确：它不能直接让上下两张纸独立移动。如果后续交互确实需要剥离或改变开口，需另制透明前景与补全底纸，不能拉伸整张图冒充物理变化。

### 姓名处理决策尚未完成

- 先比较真实字形：Y 的分叉、U 的底部、A 的内白、G 的开口及 W 的节奏。
- 字形许可确认后才进入项目；不从概念图猜一个字体名称并声称匹配。
- 优先测试真实网页字体配独立材质遮罩。若最后选择固定姓名字形资产，保留唯一语义 h1，装饰图层对辅助技术隐藏。
- 不使用大幅 `scaleX` 压缩普通系统字替代字形设计。
- 字体、墨迹与黑纸应有明确层次；不能把均匀噪声铺到字上就宣布完成。

### 信号处理决策尚未完成

- 先确定静止轮廓。需要长短不同的簇、细微不规则高频和低幅连接段。
- 亮芯、暗绿密度与辉光分开判断；不做轮廓锋利的发光柱状图。
- 不声称它是真实音频可视化，除非后来接入明确音源。
- 保留原图的交互意图，但拖动后的内容回报尚未确认。正式可操作页面不能只有“CHANNEL OPEN”文案变化，也不能用假链接掩盖未完成区域。

## 材料验收

检查候选原图，以及缩放至参考尺寸后纸边的表现：

- [ ] 所有姓名、导航、数字、波形、绿光和蓝墨均已移除。
- [ ] 开口仍在原位置，上下轮廓的主要转折接近参考，没有变成一根规整白条。
- [ ] 黑纸覆盖浅色底纸的前后关系明确，没有漂浮白纸、金属封边或厚重浮雕感。
- [ ] 纤维以局部细节出现，没有整条边缘相同的毛绒光圈。
- [ ] 黑场没有蜂窝、编织纹理、规则网点或密集垂直条纹。
- [ ] 白纸是冷中性灰白，不是黄色羊皮纸；没有夸张中心高光。
- [ ] 实际尺寸已记录；分辨率不足就明确限制用途，不能把插值放大称为新增细节。

生成候选先放在 `app/reference/production/hero-00/`，不进入 `public/`，不被现有首页引用。这样未经批准的材料不会混进正在浏览的页面。

## 后续浏览器验收顺序

1. 材料候选与原图单独比较，通过后制作姓名样张。
2. 固定参考比例，组合材料、姓名、信号与 HTML 文本。禁止播放动画干扰静态判断。
3. 同尺寸截图并排查看，必要时使用可调透明度叠图。先判构图、再判字形、再判材料、最后判小字。
4. 核对真实链接目标、可见标题、键盘焦点、触屏等价入口；DOM 中存在不代表屏幕上可见。
5. 用户认可静态浏览器结果后，只加入一个局部交互；再次截图与实际操作验证。
6. 验证其他宽高比、手机、减少动态效果模式、资源加载失败与 WebGL 不可用时的可读页面。

每次报告必须说明查看路径、哪些已完成、哪些是占位、有没有修改首页和线上环境。不要用通过单元测试或 HTTP 200 代替视觉验收，也不要用未经校准的“还原百分比”承诺效果。
